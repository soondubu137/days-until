# Days Until — icon set

The mark is the popover's runway: three days gone, today's mark with its dot, the days ahead with the weekend taller, and the house waiting at the end. It's drawn on Apple's 1024 pt icon grid and kept in macOS's own colours: system blue and the system grays.

Every file is generated by [`scripts/make-icons.py`](../scripts/make-icons.py), including the icon the app itself uses. Change the drawing there and run it again; don't edit the files by hand.

## The app's icon

The app uses [`DaysUntil/AppIcon.icon`](../DaysUntil/AppIcon.icon), in Icon Composer's format. It holds the same drawing, split into layers: the house and its circle, today's mark, and the ticks.

- **macOS 26:** the system draws it in Liquid Glass, and in Dark, Clear and Tinted modes. The blue parts are opaque glass, so the blue keeps its strength; the ticks are plain.
- **macOS 13 to 15:** Xcode makes a flat icon from the same file.
- **Editing:** Icon Composer can open the file to preview it, but the script overwrites it, so make lasting changes in the script.

The PNGs in `assets/04-app-icon` are for everything else, like a website or the README.

| Folder | What | Files |
|---|---|---|
| `assets/01-mark` | The runway alone, for small spaces and one-colour use | SVG, PNG at 128–1024 px wide |
| `assets/02-horizontal` | Icon and wordmark side by side | SVG, PNG at 128–1024 px wide |
| `assets/03-stacked` | Icon over the wordmark | SVG, PNG at 128–1024 px wide |
| `assets/04-app-icon` | The macOS app icon, with its 100 pt margin | SVG, PNG at 16–1024 px |
| `assets/05-favicon` | The small icon, filling its square | SVG, PNG at 16, 32 and 48 px |

Each mark and lockup comes in four versions:

- **No suffix:** colour, for light backgrounds.
- **`-dark`:** colour, for dark backgrounds. The lockups use the dark app icon and a white wordmark.
- **`-black` and `-white`:** one ink. Days gone and days ahead become two strengths of it, and the house is cut out of the well.

In colour, the lockups use the app icon, the way Apple presents its own apps. In one ink, they use the flat mark.

## Details

- **Colours:** the mark uses system blue (`#007AFF`, or `#0A84FF` on dark) and the system grays. The app icon uses a gradient of the same blue. The wordmark is `#1D1D1F`, or `#F5F5F7` on dark.
- **Wordmark:** "Days Until" in Inter SemiBold at −0.02 em tracking, converted to outlines, so no font is needed to view it. Inter is under the SIL Open Font License; SF Pro's licence doesn't cover logos.
- **The house is our own.** The app shows the SF Symbol `house`, but Apple doesn't allow SF Symbols, or glyphs confusingly similar to them, in app icons or logos. Ours shares the idea (an overhanging roof, a chimney on the right slope, a door) without copying the symbol.
- **Small sizes:** at 16 and 32 px the app icon and favicon use simpler artwork, with one tick either side of today, heavier strokes and a bigger well, so they don't blur into a smudge. `days-until-icon-small.svg` is that artwork.
- **Appearances:** `days-until-icon-dark` and `days-until-icon-tinted` show the icon in macOS 26's Dark and Tinted modes. Tinted uses teal as a stand-in for the colour the person picks.
- **No menu bar icon.** The menu bar item shows each countdown's own symbol, so the mark never appears there.

## Rebuilding

```bash
scripts/make-icons.py
```

This needs Python 3 with Pillow, and Google Chrome in `/Applications`. Chrome renders each SVG at 2048 px, and Pillow scales it down to each size. The script replaces `assets` entirely.
